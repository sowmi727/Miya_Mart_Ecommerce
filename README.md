# 🛍️ Miya Mart – Online Shopping Website

## 📌 Project Overview
Miya Mart is a Django-based online shopping website that allows users to browse products, search for items, add products to their cart, and place orders online.

## ✨ Features
- User-friendly Home Page
- Product Display
- Product Categories
- Product Search
- Add to Cart
- Increase and Decrease Product Quantity
- Remove Products from Cart
- Checkout Page
- Payment Method Selection
- Order Success Page
- Django Admin Panel for Product and Order Management

## 🛠️ Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/sowmi727/Miya_Mart_Ecommerce.git

2. Open the project folder:

```bash
cd Miya-Mart-Ecommerce
```

3. Install Django:

```bash
pip install django pillow
```

4. Run migrations:

```bash
python manage.py migrate
```

5. Start the development server:

```bash
python manage.py runserver
```

6. Open in browser:

```text
http://127.0.0.1:8000/
```

## 💳 Payment Information
The project includes Cash on Delivery, UPI Demo, and Card Demo payment selections. These are demonstration options and do not process real payments.
